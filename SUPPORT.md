# Support

OrangeServer is a community project. Support is best-effort.

## Choose the right channel

- Usage and deployment questions: read [docs/README.md](docs/README.md), then
  open a GitHub Discussion if enabled.
- Reproducible product bugs: open a bug report in the issue tracker.
- Focused feature proposals: open a feature request.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public
  issue.

## Information to include

- OrangeServer version or commit;
- Docker/physical/Kubernetes deployment;
- operating system, browser, Python and Node versions where relevant;
- exact reproduction steps and expected/actual behavior;
- HTTP status, browser console error, and minimal server log excerpt;
- checks already attempted.

Before posting, replace all:

- API keys, passwords, cookies, tokens, private keys and connection strings;
- internal IPs, hostnames, usernames, asset aliases and deployment paths;
- audit records, command output and personal information;
- screenshots containing real infrastructure or account details.

Use `example.com`, documentation address ranges, and synthetic assets in a
minimal reproduction.

## What maintainers cannot provide

- emergency production operations;
- recovery of lost passwords, Fernet keys, database data, or SSH credentials;
- access to or debugging of private infrastructure;
- guarantees for unsupported forks, modified builds, or outdated versions;
- legal, compliance, or security certification advice.
